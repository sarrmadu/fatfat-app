# FatFat-App — Frontend

Interface web de FatFat-App (Next.js + React + Leaflet), pour la gestion et le suivi de
tournées de livraison à Dakar, Thiès et Mbour. Se connecte au backend `fatfat-app-backend`
via son API REST.

## Prérequis

- Node.js 18+
- Le backend `fatfat-app-backend` déployé ou lancé en local (voir son propre README)
